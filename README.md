# GiveAidNGO

**GIVE-AID** is a comprehensive, production-grade NGO Management System built with **ASP.NET Core 9.0 MVC**, C#, Entity Framework Core, SQL Server, and Bootstrap 5.

---

## 🌟 Overview & Core Features
- **Public Humanitarian Portal:**
  - Dynamic Relief Programmes & Causes catalog with real-time funding progress bars.
  - Interactive Visual Media & Field Photo Gallery.
  - Transparent Strategic Partners & Associated NGOs directories.
  - Comprehensive About Us pages covering Mission, Leadership, Achievements, Careers, and Supporter recognition.
  - Help Centre & Support Desk with FAQ accordion and query submission system.
- **Relief Donation Flow (`/donate`):**
  - High-conversion split-screen layout with 256-bit SSL encrypted card authorization.
  - Interactive contribution impact matrix with instant receipt generation.
- **Member Self-Service (`/account/register`, `/member`):**
  - Member self-registration, profile management, donation history, and programme volunteering.
  - Referral system ("Invite a Friend") with unique invitation links.
- **Admin Management Portal (`/Admin`):**
  - Executive KPI analytics dashboard with Chart.js visualizations.
  - Complete CMS for Causes, Field Programmes, Media Gallery, Partners, Associated NGOs, and Donor Financial Records.
  - Role-based security with audit trail logging for all administrative operations.

---

## 🛠️ Tech Stack & Architecture
- **Framework:** ASP.NET Core 9.0 MVC
- **Language:** C# 13
- **ORM & Database:** Entity Framework Core 9.0, Microsoft SQL Server
- **Security & Identity:** ASP.NET Core Identity, PBKDF2 Password Hashing, Anti-Forgery CSRF, XSS protection
- **Frontend & UI:** Bootstrap 5.3 (Obsidian Dark Theme), Bootstrap Icons, Chart.js
